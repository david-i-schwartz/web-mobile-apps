With boards, the grid is whole boards, as many across and down as the person chooses (FIG’s pegboards, BIG’s sheets). Without boards, the person sets a width and the height follows the picture. Widths are counted in cells.

Get the Files

For the Web

Phones and tablets, iPhones and iPads above all, can only run these apps from a web address. The web folder holds what to put on a web host such as GitHub Pages: the app, Home Screen icons, and an offline helper so the Home Screen app opens with no connection. Unzip it into a folder on the host, named after the app.

Build Brief

Hand the app file and this brief to any AI assistant (Claude, ChatGPT, Gemini, Qwen or another) to add the app’s own features. It explains where new code goes and the rules FIG and BIG follow. Write what you want next where it says so.

Test Brief

For an independent check, give the finished app and this brief to a different AI from the one that built it. For example, if Claude built it, ask ChatGPT, Gemini or Qwen to test it. The brief lists the house rules and a checklist for the parts this app has, and asks for a verdict, a pass/fail table and problems with fixes.

How It Works
  • An app is one HTML file: the core (styles and the parts you ticked), the app’s spec as a block of data at the top, and four sections that belong to the app alone: APP CSS, APP STAGE, APP PANELS and APP CODE.
  • The core grew from what FIG and BIG share: the same stylesheet, picture pipeline, editing, progress, project files and file saving.
  • To add features, put them in the APP sections, by hand or with any AI and the build brief. To fix or improve something every app has, change the core instead, in the generator’s kit.
  • Nothing depends on one AI. The apps run in any browser, the briefs are plain text, and the kit runs on Node. Have one AI build and a different one test, using the test brief.
  • When the core improves, open each app here with Open an app to upgrade and download it again. Its spec and APP sections carry over.
  • To use an app on a phone or tablet, put its web folder on a web host. Each app shows the two or three taps that add it to the Home Screen, and says when it’s already there.
  • The kit also has a command-line version for Claude Code or any computer with Node: node cli.js new spec.json app.html, and node cli.js upgrade old.html new.html.
